# Customer Shopping Behavior & Segmentation Analysis

## Project Overview

This project analyzes customer shopping behavior using Power BI to identify patterns in revenue, product preferences, subscription behavior, age groups, and customer spending.

A customer segmentation model was developed using DAX to divide 3,900 customers into four spending groups: High Spender, Medium-High Spender, Medium-Low Spender, and Low Spender.

The final interactive Power BI dashboard allows users to explore customer behavior using dynamic filters and provides business insights to support customer targeting, marketing, and retention decisions.
